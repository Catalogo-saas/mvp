# Strom on an existing storefront

Mode: Persuade, with Operate constraints in the merchant editor.

## Direction contract

THESIS: Present Strom as a configured instance of Vene, never a fourth template or a private runtime branch.

OWN-WORLD: Inherit Vene's Manrope/Sora typography, shared commerce components and responsive layouts. Strom contributes its public logo, yellow/black palette and sourced product photography through ordinary settings.

STORY: Visitors discover supplements and six categories, browse real product photography, and try the explicitly illustrative checkout. Merchants see and edit the same content rendered publicly.

FIRST VIEWPORT: Existing announcement and header, then an editable yellow banner with product imagery; desktop copy is left and products right, mobile artwork places products above copy. The whole banner links to the catalog.

FORM: Existing Vene implementation, selected to correct the originally mistaken exclusive template. No new-world seed: user explicitly requires an existing template. Standard banner controls, category mosaics and checkout remain unchanged.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
